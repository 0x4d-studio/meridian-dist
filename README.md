# Meridian — Downloads

Public distribution point for the Meridian VS Code extension (`.vsix`).
Source lives in a private repo; only release artifacts are published here.

## Install

1. Download the latest `meridian-<version>.vsix` from the [Releases](../../releases) page.
2. In VS Code / Cursor: Extensions panel → `⋯` menu → **Install from VSIX…**, or run:
   `code --install-extension meridian-<version>.vsix`
